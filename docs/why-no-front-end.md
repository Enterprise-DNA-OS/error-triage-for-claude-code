# Why there is no front end

The daily jobs are questions and accountable decisions: what failed, who owns the fix, which commitment is late and whether the fault returned. The CLI answers these from the database; the agent helps the operator ask and act. Branded HTML documents and read-only views show the evidence. They contain no controls that write data.

A screen offers clickable stack exploration, session playback, mobile access and immediate visual navigation. This base does not supply them. It also does not supply a real-time hosted collector or the operational guarantees of a monitoring service. The free capture helper writes local files and the importer runs in batches. Database access, file scheduling and production collection need an installation plan.

For a team that wants those interfaces or a continuing managed feed, Enterprise DNA builds them around the owned database as part of its version. Keep an existing collection service until the new one is proven. Do not read a quiet report as evidence that an application is healthy.
